# Контракт backend-core → backend-ai

`backend-core` должен вызывать AI только после проверки JWT и права пользователя на запрошенный портфель.

Рекомендуемый вызов:

```http
POST /advisor/analyze
X-AI-Token: <internal token>
Content-Type: application/json
```

В `portfolio` должны попадать только данные текущего пользователя. Нельзя передавать в AI сервис `UserId` из запроса клиента как основание для доступа.

Для Dashboard рекомендуется вызывать AI после изменения портфеля/импорта отчёта и сохранять последний результат, а не запускать модель на каждый GET Dashboard.
